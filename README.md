# 🛍️ E-Commerce Flutter App

A modern and responsive E-Commerce mobile application built with Flutter & Dart, designed to provide a complete shopping experience — from onboarding and authentication to browsing products, managing the cart, checkout, orders, and user account.
## ✨ Features

### 🔐 Authentication
- Onboarding
- Login
- Sign Up
- Reset Password

### 🏠 Home & Products
- Browse products
- Product categories
- Product details
- Search products
- Discover products
- Filter products

### ❤️ Saved Items
- Add products to favorites
- View saved products
- Manage saved items

### 🛒 Cart
- Add products to cart
- Increase / decrease quantity
- Remove products
- View cart details

### 💳 Checkout & Payment
- Manage delivery addresses
- Add new address
- Select payment method
- Add new card
- Order summary
- Order confirmation

### 📦 Orders
- View ongoing orders
- View completed orders
- Track orders
- View order status

### 👤 Account
- Account management
- Notifications
- Help Center
- FAQs
- Customer Service
